# Spendly Mini Project Report

## Aim
Develop a Python desktop expense tracker and analytics dashboard.

## Technologies
Python, Tkinter, Pandas, NumPy and Matplotlib.

## Modules
- Dashboard
- Expense Management
- Analytics
- History
- Budgets
- Categories
- Settings

## Syllabus Coverage
Unit 1: Python fundamentals, functions, CSV/file handling and GUI event logic.
Unit 2: NumPy statistics, Pandas DataFrames and Matplotlib visualization.
Unit 3: Tkinter GUI, widgets, buttons, Treeview, navigation and event handling.

## Visualizations
- Line chart
- Donut/pie chart
- Bar chart
- Histogram
