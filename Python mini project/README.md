# Spendly — Functional Python Mini Project

This is the functional version of the approved Spendly dashboard.

## Pages
Dashboard, Expenses, Analytics, History, Budgets, Categories, Settings, Help Center.

## Features
- Add Expense
- Edit Expense (double-click a row in Expenses)
- Filters
- CSV persistence
- CSV export
- Dashboard KPIs
- Spending Trend chart
- Category donut chart
- Category bar chart
- Expense distribution histogram

## Run
Open CMD in this folder:

python -m pip install -r requirements.txt
python main.py

The project starts with the same 12 demo transactions used for the approved UI.
