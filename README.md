# Spendly – Personal Expense Tracker

Spendly is a Python-based desktop application designed to help users record, organize, and analyze their daily expenses.

## Features
- Record expenses with date, category, description, amount, and payment method.
- View expense summaries through an interactive dashboard.
- Analyze spending patterns using charts and visual reports.
- Organize transactions for easier expense management.

## Technologies Used
- Python
- Graphical User Interface (GUI)
- Data Processing
- Data Visualization

## Objective
The objective of Spendly is to demonstrate Python programming concepts through a practical expense management application that helps users understand and organize their spending habits.

## Project Type
Python Mini Project – Expense Management System
